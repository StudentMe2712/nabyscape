## 1. Концепция продукта и визуальная философия

**Desktopia** — премиальный десктопный динамический остров (Dynamic Island / Top Notch) для Windows, сочетающий нативную прозрачность WPF (`AllowsTransparency="True"`, `WindowStyle="None"`), анимацию аппаратного уровня, сдержанную цветовую палитру тёплого обсидиана и модули личной эффективности.

### Главные принципы канона 4.0:
1. **Цветовая палитра тёплого обсидиана (Warm Obsidian Palette):**
   * **Основной фон:** `#101113`
   * **Карточки:** `#1B1B1E`
   * **Поверхности:** `#252321`
   * **Основной акцент:** `#E58A43` (загорается строго при действии или наведении)
   * **Медный оттенок:** `#B96A38`
   * **Основной текст:** `#F2E9DF`
   * **Вторичный текст:** `#96918B`
2. **Закон визуальной гигиены:**
   * Отсутствие постоянного светящегося оранжевого неона по краям карточек.
   * Рамка в покое — ультратонкая (`1px`), приглушённая (`#252321` или `rgba(242, 233, 223, 0.06)`).
   * Акцент `#E58A43` появляется только на активных элементах (активный чекбокс, наведение, ползунок, кнопка «Засчитать»).
3. **Навигация Dot Navigation (Эстетика NabyScape):**
   * В шапке используются аккуратные точки: неактивная точка `6×6px` (`#353330`), активная вкладка — горизонтальная округлая пилюля `16×6px` (`#E58A43`).
   * Никаких вытянутых овальных рамок-гусениц.
4. **Адаптивный видеоплеер Daily Reset (Любые форматы):**
   * В плеере строго используется **`Stretch="Uniform"`**!
   * Любые вертикальные видео (Reels / Shorts / TikTok 9:16), горизонтальные 16:9 и квадратные 1:1 отображаются **целиком без малейшей обрезки**.
   * Окно открывается в кинематографичном Full HD разрешении (`1920×1080px`, либо адаптивно `1600×900px`).
   * Кнопка «Засчитать выполнение» активируется строго после завершения воспроизведения.
5. **Строгий порядок вкладок островка (Дефолт — Задачи):**
   1. **Задачи** (Tasks) — открывается по умолчанию при разворачивании.
   2. **Заметки** (Notes)
   3. **Плеер** (Music)
   4. **Daily Reset** (Перезагрузка дня)
   5. **Таймер** (Timer) — с поддержкой прокрутки колесом мыши и ввода с клавиатуры.
   6. **Помодоро / Фокус** (Focus)
   7. **Система** (System)
6. **Режим присутствия Desktop-Only (TranslucentTB Logic):**
   * Островок активен только тогда, когда на экране нет развёрнутых окон приложений.
   * Появление плашки — при подведении курсора к верхней кромке экрана (`Y <= 4px`).
   * Раскрытие панели вниз — строго по клику ЛКМ на иконку агента Naby (Hover отключен).
7. **100% Русская локализация и бренд Desktopia:**
   * Полное отсутствие английских строк в интерфейсе, уведомлениях и окне настроек.
   * Проект во всех окнах, манифестах и трее именуется **Desktopia**.
